# SCI稿件定位与结论边界

## 推荐英文题目

**Leakage-Controlled Feature Selection and Random-Forest Ensembles for Network Intrusion Detection: A Reproducible Multi-Dataset Study**

## 推荐投稿定位

本文定位为一项面向网络入侵检测的、无数据泄漏控制的可复现实证研究，而不是宣称提出了普适最优的新分类器。核心价值包括：

1. 对公开流量数据执行可追溯的数据清洗、全局去重、跨标签冲突审计和来源记录；
2. 将归一化、特征选择和超参数选择限制在训练数据内，使用统一协议比较不同模型与特征选择方法；
3. 通过平衡子集、自然分布敏感性、独立 NSL-KDD 基准、共享扰动、概率质量和统计检验，分析方法在不同评价条件下的适用边界。

## 研究问题

- **RQ1：** 在严格训练集内拟合的条件下，χ²特征选择能否在减少输入维度的同时保持随机森林性能？
- **RQ2：** 基于验证集单树性能的加权投票是否相对等权投票产生稳定、可检验的预测改进？
- **RQ3：** 数据分布、去重协议、类别不平衡和评价指标变化会如何影响入侵检测结论？

## 威胁模型与实验边界

- 检测器输入为公开数据集提供的网络流统计特征，不解析真实在线数据包。
- 攻击标签由公开数据集给出，研究不执行主动扫描、渗透、攻击或未授权流量采集。
- 模型目标是离线监督分类，不等同于入侵响应、攻击溯源或实时网关防护。
- 结果只对明确给出的数据版本、标签映射、去重协议、抽样规则和随机划分有效。

## 可以主张的结论

- 训练集内 χ² 选择可将 78 个输入特征压缩到 60 个，并在当前 CIC-IDS2017 平衡研究子集上基本保持 RF 的 Macro-F1。
- 特征集合在训练折之间具有可量化的稳定性，但稳定性不代表因果作用。
- 加权投票在当前数据和参数下与等权投票逐样本一致，未显示额外统计优势；该机制应作为适用性分析，而非已证实的性能创新。
- 自然分布下 Accuracy、Balanced Accuracy 和 Macro-F1 存在明显差异，类别级指标对困难类别分析是必要的。
- NSL-KDD 结果是独立公开数据集基准，不构成跨数据集迁移成功的证据。
- 离线 predict 延迟可以作为计算成本基准，但不能等同于真实网关端到端部署性能。

## 禁止使用的表述

以下表述只有在新增实验直接提供证据后才可使用；当前稿件不得使用：

- “在 CIC-IDS2017 全量数据上达到 95%/97%”；
- “本文算法显著优于所有基线”或“达到 SOTA”；
- “已证明跨数据集泛化”或“已完成真实校园网关部署”；
- “加权随机森林显著提升检测精度”；
- “时间外/跨场景泛化能力已得到验证”。

## SCI 级必须补齐的证据

1. 至少一个统一调参的梯度提升强基线（XGBoost、LightGBM 或同等级模型）；
2. 外层重复划分、内层参数选择的嵌套验证，避免把固定测试结果当作泛化估计；
3. 平衡与自然分布两种评价口径，以及类别级指标、概率质量和置信区间；
4. 预先定义比较族，使用配对置换检验、McNemar 检验、效应量和 Holm 校正；
5. 完整的数据版本、文件哈希、代码、配置、运行环境和逐样本预测材料；
6. 英文稿按目标期刊 Guide for Authors 重新组织，压缩附录表格并强化威胁模型和局限性。
