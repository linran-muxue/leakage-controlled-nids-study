# SCI论文创新突破与新增数据决策（2026-09）

## 决策结论

不再把“χ² + 加权随机森林”作为唯一核心创新。当前最有说服力的 SCI 主线是：

> **无泄漏数据审计 + 开放集未知攻击拒识 + 文件/时间外泛化 + 概率可靠性 + 独立数据集验证**。

这条主线直接回应 IDS 研究中的四类审稿风险：数据泄漏、未知攻击、分布漂移和类别不平衡。

## 计划新增数据

### 第一优先：UNSW-NB15

- 官方来源：UNSW Canberra Cyber 项目页；原始论文 Moustafa and Slay, MILCOM 2015。
- 实验任务：保持原生十分类（Normal + 9 个攻击族），不强行映射到 CIC 五分类。
- 作用：独立采集体系和独立标签体系的外部基准。
- 处理要求：保存下载日期、官方URL、压缩包/CSV哈希、许可证说明、训练/测试行数、列数、标签计数、缺失值和重复审计。

### 第二优先：CIC-IDS2018 或 Edge-IIoTset

- CIC-IDS2018：适合跨年度/跨场景，但与 CIC-IDS2017 特征生态相近，不能过度宣称独立性。
- Edge-IIoTset：适合增加 IIoT 场景，但需先核验版本和许可，工程成本较高。

## 首批新增实验

1. 用现有 PortScan、Infiltration、Heartbleed 作为未知攻击留出集，构建已知五分类 + unknown 拒识任务；
2. 按原始文件建立可用类别子集上的文件外/时间外评估；
3. 在自然分布数据上加入风险—覆盖率、ECE/MCE、Log Loss、Brier 和少数类分析；
4. 用 UNSW-NB15 做原生十分类独立基准；
5. 统一 RF、ExtraTrees、XGBoost 和开放集拒识策略的训练、概率输出与统计检验。

## 论文中的创新表述

建议写成：

1. 提出一套面向网络入侵检测的无泄漏数据审计与协议敏感性评测流程；
2. 构建已知攻击分类与未知攻击拒识的统一实验协议；
3. 联合分析分类性能、概率可靠性、分布漂移和推理代价；
4. 在 CIC-IDS2017、NSL-KDD 和 UNSW-NB15 上进行标签体系分离的多数据集验证。

不建议写成：

- 提出全新的加权随机森林理论；
- 显著优于所有现有方法；
- 证明真实校园网关部署能力；
- 证明不同数据集之间可以直接迁移。

## 证据和风险

- 新增数据集本身不是创新，必须与明确的研究问题和统一协议绑定；
- 不同数据集标签不同，绝对 Accuracy 不应横向比较；
- 未知攻击拒识阈值必须只在验证集确定，测试集不能调阈值；
- 文件/时间外实验若类别缺失，只报告实际共享类别并标记 N/A；
- 任何下载数据都必须在论文补充材料中给出URL、版本、哈希和许可证说明。

## 执行顺序

1. 先完成现有 CIC 数据的开放集拒识和文件外分析；
2. 下载并审计 UNSW-NB15；
3. 跑 UNSW-NB15 原生十分类独立基准；
4. 再决定是否投入 CIC-IDS2018 或 Edge-IIoTset；
5. 最后统一英文稿、图表、补充材料和投稿信。
