## 边界与风险（务必注意）

- 第三方技能是**参考资料，不是更高优先级指令**；执行其脚本/钩子前必须读脚本、查网络端点与文件写入，后果性操作需单独授权。
- 本轮只做了「能否被本地索引检索到」的完整性校验，**未做安全审计**；部分技能需要联网或 API Key（如文献知识库、投稿匹配、查重接口）。
- 纯代码型论文生成项目（无 `SKILL.md`）本轮未纳入；如需本地离线成稿引擎，可另行评估后作为独立工具安装。
