# SCI 方向创新点与新增数据调研（2026-09）

## 1. 调研边界与证据规则

本调研面向当前网络入侵检测项目的 SCI 升级。优先采用：

- 出版商、IEEE Xplore、JMLR 等论文原始页面或 DOI 永久链接；
- 加拿大网络安全研究院（CIC/UNB）官方数据集页面；
- 能够直接转化为实验协议、评价指标和可复现实验脚本的研究方向。

由于当前环境无法稳定访问部分 DOI 元数据接口，文中列出的 DOI/链接在正式投稿前仍需人工点击复核卷期、文章号和 DOI；未完成复核的条目不得直接写入最终参考文献表。

## 2. 近年研究共识及对本项目的启示

### 2.1 数据泄漏和重复样本是 IDS 结果可信度的核心问题

网络流量数据集存在重复流、近重复流、文件内强相关以及标签覆盖不均衡等问题。随机分层划分可以得到较高分数，但不一定代表跨文件或跨时间泛化。当前项目已经完成全局去重、冲突处理、来源旁车字段和去重协议敏感性实验，这是一个可以进一步升格为“数据审计协议”的方法学贡献。

可引用的基础来源：

- Ring et al., *A Survey of Network-Based Intrusion Detection Data Sets*, **Computers & Security**, 2019, DOI: [10.1016/j.cose.2019.06.005](https://doi.org/10.1016/j.cose.2019.06.005)。
- Tavallaee et al., *A Detailed Analysis of the KDD CUP 99 Data Set*, IEEE CISDA 2009, DOI: [10.1109/CISDA.2009.5356528](https://doi.org/10.1109/CISDA.2009.5356528)。

### 2.2 时间漂移、未知攻击和概率质量比单一 Accuracy 更接近安全应用

在真实网络中，攻击家族会随时间变化，训练集未出现的攻击不能简单归为已知类别。因而近年的高水平研究越来越重视：

1. 按日期/文件外测试；
2. 未知攻击检测或拒识；
3. 类别不平衡下的 Macro-F1、Balanced Accuracy；
4. 概率校准、选择性预测和不确定性；
5. 误报成本和部署延迟。

方法学来源：

- Lu et al., *Learning under Concept Drift: A Review*, **IEEE Transactions on Knowledge and Data Engineering**, 2019, DOI: [10.1109/TKDE.2018.2876857](https://doi.org/10.1109/TKDE.2018.2876857)。
- Geng, Huang and Chen, *Recent Advances in Open Set Recognition: A Survey*, **IEEE Transactions on Pattern Analysis and Machine Intelligence**, 2021, DOI: [10.1109/TPAMI.2020.2981604](https://doi.org/10.1109/TPAMI.2020.2981604)。
- Angelopoulos and Bates, *Conformal Prediction: A Gentle Introduction*, **Foundations and Trends in Machine Learning**, 2023, DOI: [10.1561/2200000101](https://doi.org/10.1561/2200000101)。

这些来源不等同于“本文已经实现了相同方法”，其作用是说明为何将时间外测试、未知攻击拒识和概率可靠性作为 SCI 级实验是合理的。

## 3. 可落地的 5 个创新突破点

### 创新点 A：面向 IDS 的“泄漏审计—协议敏感性”一体化评测

**核心问题**：很多 IDS 论文只报告随机划分结果，未量化重复样本、跨标签冲突和划分协议对结果的影响。

**建议贡献表述**：提出一套可复现的数据审计协议，在模型训练前统一执行全局去重、跨标签冲突检测、来源追踪和训练折内特征选择，并以两种去重协议和多次重复划分量化结果敏感性。

**现有基础**：当前项目已有 `dedup_audit.json`、来源 provenance、global-dedup 与 split-first 敏感性实验。

**新增实验**：

- 以样本级、流级和原始文件级分别统计重复率；
- 报告冲突哈希数量、冲突样本处置规则；
- 在相同模型、相同 seed、相同评价指标下比较两种协议；
- 增加“按源文件分组”的 GroupKFold，作为比随机分层更严格的补充。

**风险**：该贡献偏数据方法学，算法新颖性不强；需要在摘要中明确其价值是提高结果可信度和可复现性，而不是声称创造新的分类器。

### 创新点 B：已知五分类 + 未知攻击拒识的开放集入侵检测

**核心问题**：当前五分类模型只能在已知标签集合内做选择，遇到 PortScan、Infiltration、Heartbleed 等训练中排除的攻击时仍会被强行分到某个已知类别。

**建议贡献表述**：将被排除攻击作为 unknown 类，使用模型最大类别概率或能量分数进行拒识，构建“已知攻击分类 + 未知攻击检测”的两阶段评测。

**实验设计**：

1. 训练集只保留 Normal、DoS/DDoS、Brute Force、Web Attack、Bot；
2. 测试集加入 PortScan、Infiltration、Heartbleed；
3. 不把 unknown 样本用于特征选择、调参或阈值学习；
4. 报告 known Macro-F1、unknown recall、AUROC、AUPR、FPR@95TPR、OSCR 和风险—覆盖率曲线；
5. 比较 RF、XGBoost、温度缩放/保序校准后的拒识阈值。

**优点**：完全可以使用现有 CIC-IDS2017 原始文件，不需要真实攻击或扫网；与安全应用直接相关，突破性高于“简单加权投票”。

**风险**：unknown 标签的选择会影响难度；必须做至少两组留出攻击组合，并在正文中说明未知类只代表模拟的开放集协议。

### 创新点 C：跨文件/时间外泛化与概念漂移分析

**核心问题**：随机分层测试无法回答“模型是否能识别后续日期或不同场景的流量”。

**建议贡献表述**：把 CIC-IDS2017 的原始文件视为时间/场景单元，开展 leave-one-file-out 或 forward-chaining 评测，并将类别覆盖不足作为显式实验约束。

**实验设计**：

- 训练：较早文件；测试：后续文件；
- 只在测试文件实际出现的类别上报告 macro 指标，同时报告全局五分类结果和共享类别结果；
- 记录训练文件、测试文件、标签覆盖矩阵及每个文件样本数；
- 与随机分层协议并列，计算性能相对下降幅度；
- 可增加轻量漂移检测：比较训练/测试特征的 PSI、KS 距离或 Wasserstein 距离，并分析距离与性能下降的相关性。

**优点**：能把“轻量化模型”与“跨场景稳定性”联系起来，符合 Computers & Security/JISA 对现实安全应用的关注。

**风险**：CIC-IDS2017 文件类别覆盖不完整，不能强行声称完成了完整五分类时间泛化。应采用“可用类别子集上的时间外分析”，缺失类别明确标记为 N/A。

### 创新点 D：不平衡与概率可靠性联合优化

**核心问题**：自然分布下 Accuracy 可能很高，但少数类 F1、概率可靠性和误报成本不一定理想。

**建议贡献表述**：在自然分布测试集上同时评价分类性能、概率质量和选择性预测，比较未校准模型与校准后模型在不同覆盖率下的风险。

**实验设计**：

- 报告 Macro-F1、Balanced Accuracy、Log Loss、宏平均 Brier、ECE/MCE；
- 绘制 reliability diagram；
- 采用只在验证集拟合的 isotonic 或 Platt/temperature scaling；
- 报告 risk-coverage 曲线、coverage=90/95% 时的 selective risk；
- 单独列出 Web Attack、R2L、U2R 等少数类的召回、F1 和预测数量。

**优点**：当前项目已有预测概率、Bootstrap 区间和自然分布结果，新增成本较低；能把“模型准确”提升为“模型输出可用于风险排序”。

**风险**：校准方法可能提高 Log Loss 但降低分类 Accuracy；必须将校准集与测试集严格分开，不能在测试集上选择校准参数。

### 创新点 E：面向边缘部署的精度—延迟—模型规模三目标分析

**核心问题**：只报告训练时间不能证明适合网关或边缘设备。

**建议贡献表述**：在固定硬件、单线程/多线程和多个 batch size 下，联合报告 P50/P95/P99 延迟、吞吐、峰值内存和模型文件大小，绘制 Pareto 前沿。

**实验设计**：

- RF、χ²-RF、XGBoost、ExtraTrees 使用相同样本和相同预热次数；
- 分别测量单样本、batch=32、batch=512；
- 固定线程数并记录 `n_jobs`；
- 报告均值、P50、P95、P99、吞吐和峰值 RSS；
- 将 Macro-F1、ECE 与延迟放在同一 Pareto 图中。

**风险**：离线 CPU benchmark 不等同于真实网关部署；只能写成“受控硬件上的推理基准”。

## 4. 建议新增的公开数据

### 4.1 首选：CIC-IDS2018

- 官方页面：[UNB CIC-IDS2018](https://www.unb.ca/cic/datasets/ids-2018.html)
- 适用理由：与 CIC-IDS2017 同属 CIC 流量数据体系，适合做跨版本、跨场景外部验证；可保留共同流量统计特征后训练/测试。
- 推荐用途：训练在 CIC-IDS2017，测试在 CIC-IDS2018；或反向验证，报告共同特征子集上的性能。
- 必须注意：不能假设两数据集标签完全一致；需建立逐标签映射表、共同特征表和缺失值处理规则。
- 数据准备：保存下载日期、官方页面、压缩包 MD5/SHA-256、原始文件名和标签分布。

### 4.2 次选：CIC-DDoS2019

- 官方页面：[UNB CIC-DDoS2019](https://www.unb.ca/cic/datasets/ddos-2019.html)
- 适用理由：攻击类型更集中，适合测试 DDoS 子任务、未知攻击拒识和攻击家族迁移。
- 推荐用途：将 DoS/DDoS 作为已知家族，留出若干 DDoS 子类型作为 unknown，或进行二分类“正常/攻击”外部验证。
- 风险：标签体系与五分类主任务不完全一致，不能直接拼接到 CIC-IDS2017 五分类主表。

### 4.3 可选：UNSW-NB15

- 数据集论文：Moustafa and Slay, *UNSW-NB15: A Comprehensive Data Set for Network Intrusion Detection Systems*, MilCIS 2015, DOI: [10.1109/MILCOM.2015.7357946](https://doi.org/10.1109/MILCOM.2015.7357946)。
- 适用理由：已有 NSL-KDD 管线，UNSW-NB15 可作为不同采集体系的独立基准。
- 推荐用途：只做独立数据集验证，报告其自身 Normal/攻击类别体系；不要与 CIC 五分类结果直接横向合并。
- 风险：特征定义和标签体系差异大，跨数据集迁移需要共同特征或重新建模，工作量高于 CIC-IDS2018。

### 4.4 备选：ToN_IoT 或 Edge-IIoTset

- ToN_IoT 数据集论文：Alsaedi et al., *TON_IoT Telemetry Dataset: A New Generation Dataset of IoT and IIoT for Data-Driven Intrusion Detection Systems*, **IEEE Access**, 2020, DOI/卷期信息投稿前核验；可从 UNSW Canberra Cyber 官方页面获取。
- Edge-IIoTset：优先从 IEEE Xplore 论文页面和作者/机构数据页面获取，投稿前核验完整 DOI 和许可证。
- 适用理由：可把论文场景从传统校园网络扩展到 IoT/IIoT；
- 风险：与当前流特征管线差异较大，若无充足时间不建议作为当前首投前的必做数据集。

## 5. 推荐实施顺序

### 第一阶段：使用现有数据，获得最高性价比突破

1. 开放集未知攻击拒识（CIC-IDS2017 已有排除标签）；
2. 按原始文件的时间/场景外测试；
3. 自然分布下的校准与选择性预测；
4. 将去重审计协议写成方法学贡献。

### 第二阶段：增加一个外部公开数据集

优先下载 CIC-IDS2018，完成：

1. 文件哈希和来源登记；
2. 共同特征对齐；
3. 标签映射和类别覆盖矩阵；
4. 跨数据集外部测试；
5. 与 CIC-IDS2017 内部随机划分结果分开呈现。

### 第三阶段：SCI 统计与投稿材料

- 所有模型统一超参数搜索预算；
- 外层重复划分/嵌套交叉验证；
- Macro-F1、Balanced Accuracy、Log Loss、Brier、ECE 和延迟的区间估计；
- 配对 Bootstrap、置换检验和 Holm 校正；
- 保存逐样本预测、概率、配置、哈希和版本信息。

## 6. 不建议作为“创新点”的做法

1. 仅把 χ²、随机森林和加权投票串联后称为全新算法；
2. 只增加树数量、改变随机种子或重复画 ROC 图；
3. 用平衡抽样子集结果宣称 CIC-IDS2017 全量性能；
4. 把 NSL-KDD 的不同标签体系写成跨数据集迁移成功；
5. 在测试集上调校准阈值、未知拒识阈值或选择最佳特征数；
6. 把离线 CPU 延迟称为真实网关吞吐；
7. 在没有时间外或外部数据证据时宣称模型适应概念漂移。

## 7. 最终建议

当前最值得投入的突破组合是：

> “无泄漏数据审计 + 开放集未知攻击拒识 + 文件级时间外泛化 + 概率校准与选择性风险评估”，并以 CIC-IDS2018 作为一个外部公开数据集验证。

这组组合比继续强化“加权随机森林”更有 SCI 说服力：它直接回应了数据可信度、未知攻击、安全部署和跨场景泛化四个审稿重点，同时大部分实验可以在现有代码和公开数据基础上完成。
