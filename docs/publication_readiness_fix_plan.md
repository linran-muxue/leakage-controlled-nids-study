# 出刊前实验与论文一致性整改计划

**目标：** 将主实验、加权随机森林、统计检验、部署/鲁棒性与论文材料统一到同一最终配置，并形成可审计的送审版本。

**唯一实验协议：** `data_processed_audit_v2`；CIC 五分类；训练/验证/测试=70%/15%/15%；k=60；RF 与加权 RF 使用 100 棵树、`min_samples_leaf=2`；随机种子 42、2024、3407；NSL-KDD 使用训练集拟合独热编码的 v2 数据。

## 任务

- [ ] 修改扩展实验脚本，使树数、叶节点参数和输出目录可配置。
- [ ] 统一重跑主模型、加权投票、逐样本预测、Bootstrap、McNemar、配对置换、权重消融、部署和鲁棒性。
- [ ] 用同一配置重跑不平衡敏感性实验。
- [ ] 生成文件级类别覆盖审计，作为时间/场景泛化限制证据。
- [ ] 重新生成第四章、表格、图和 Word 草稿。
- [ ] 运行测试、编译检查、结果一致性检查。

## 不可由程序独立完成
