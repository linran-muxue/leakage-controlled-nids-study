# 来源页面证据留存

请由作者在可正常访问的浏览器中打开以下页面，并使用“打印 → 保存为 PDF”或截图保存页面中显示的下载、版本、引用和 Terms/License 信息：

1. CIC-IDS2017：<https://www.unb.ca/cic/datasets/ids-2017.html>
2. NSL-KDD 实际使用镜像：<https://github.com/defcom17/NSL_KDD>
3. UNSW-NB15：<https://research.unsw.edu.au/projects/unsw-nb15-dataset>

建议文件名：

- `cic_ids2017_source_YYYY-MM-DD.pdf`
- `nsl_kdd_mirror_YYYY-MM-DD.pdf`
- `unsw_nb15_source_YYYY-MM-DD.pdf`

保存后，将页面明确写出的许可证原文、版本号（如有）和 NSL-KDD commit SHA 填入：

`results_publication_final/external_data_metadata_template.json`

如果页面没有明确许可证或数字版本，请保留 `AUTHOR_TO_VERIFY`，并在论文中写明“来源页面未声明统一标准许可证/数字版本”，不要根据仓库平台或文件名推断。
