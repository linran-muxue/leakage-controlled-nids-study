# v3b Release Package Contents

This release contains the locked v3b CIC-IDS2017 research protocol and its
publication materials. Original CIC-IDS2017, NSL-KDD, and UNSW-NB15 files are
not redistributed. They must be obtained from their providers and used under
the applicable terms.

## Submission package

Contains the English and Chinese manuscripts, Highlights, graphical abstract,
cover-letter template, supplementary-material index, publication manifest,
canonical protocol, claim matrix, data-source records, figures, and the final
submission audit documents.

## Reproducibility package

Contains source code, tests, dependency locks, canonical v3b processed CSVs,
provenance sidecars, data-quality audits, locked CIC results, external native-
label benchmark results, file-coverage pressure-test results, predictions,
calibration and robustness evidence, and the publication manifest.

## Scientific boundary

The primary CIC protocol is a deduplicated, physically screened, capped
flow-level research population. It is not full-corpus performance, a complete
temporal holdout, a production deployment benchmark, or evidence of universal
algorithmic superiority. NSL-KDD and UNSW-NB15 are independent native-label
benchmarks rather than cross-dataset transfer experiments.
