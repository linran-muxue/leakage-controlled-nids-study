# 《计算机系统应用》近年网络安全与机器学习相关文章研究记录

## 说明与核验范围

本记录依据《计算机系统应用》期刊官网文章摘要页的 HTML 元数据和摘要内容整理。期刊官网页面提供题名、作者、在线发布日期、卷、期、页码、DOI、关键词、摘要以及 PDF 链接。每条均保留官网永久文章页，便于投稿前复核。由于当前工作环境的终端编码会导致中文页面正文显示乱码，中文字段以官网 UTF-8 元数据为准写入本文件；投稿前仍建议人工打开链接核对最终参考文献标点和作者姓名。

“已核验”仅表示期刊官网元数据和摘要可定位；“未核验”表示官网摘要未提供、或尚未下载全文核对的实验细节，不得据此补写论文中的具体数字。

- 英文题名：Multimodal Intrusion Detection Integrating Federated Learning with Improved TCN-BiGRU

### 1.2 面向车联网DoS攻击的混合入侵检测系统（已核验）

- 作者：郭健忠，王灿，谢斌，闵锐
- 英文题名：Hybrid Intrusion Detection System for DoS Attacks in Internet of Vehicles
- 期刊信息：《计算机系统应用》，2025，34(3)：85–93
- DOI：[10.15888/j.cnki.csa.009821](https://doi.org/10.15888/j.cnki.csa.009821)
- 官网文章页：[https://www.c-s-a.org.cn/csa/article/abstract/9821](https://www.c-s-a.org.cn/csa/article/abstract/9821)
- 官网 PDF：[http://www.c-s-a.org.cn/csa/article/pdf/9821](http://www.c-s-a.org.cn/csa/article/pdf/9821)
- 关键词：车联网；入侵检测；DoS 攻击；堆叠集成；自动编码器
- 数据与实验：Car-Hacking、CICIDS2017；已知 DoS 与未知 DoS 两种实验；报告平均测试时间。
- 方法结构：预处理和特征选择；5 种树结构监督分类器堆叠；卷积去噪自动编码器与注意力机制组成无监督异常检测模块，用于补充未知 DoS。
- 官网摘要报告：已知 DoS 检测准确率在 Car-Hacking 和 CICIDS2017 上分别为 100% 和 99.967%；未知 DoS 分别为 100% 和 83.953%；平均测试时间分别为 0.072 ms 和 0.157 ms。
- 对当前稿件的启示：该文与本文都使用 CIC-IDS2017 和树模型/集成思想，可用于说明同刊对“特征选择、集成模型、检测时间”组合的关注。本文应明确自己的五分类平衡子集和无泄漏选参边界，不能拿本文结果与其 DoS 专项结果作直接优劣比较。
- 尚未核验：5 个树分类器的具体构成、未知 DoS 的划分方式、是否按文件/时间切分、测试硬件和统计显著性。

## 4. 对当前稿件的结构性启示

1. **研究问题表述**：同刊文章通常明确指出高维冗余、类别不平衡、加密流量或未知攻击等具体问题。本文应把问题收敛为“特征冗余 + 树投票差异 + 轻量化评估”，避免同时宣称解决未知攻击、跨场景迁移和在线部署。
2. **数据集与协议**：近年论文大量采用 CIC-IDS2017、UNSW-NB15、NSL-KDD 等公开数据集，但摘要往往未交代去重、文件级切分和训练集拟合边界。本文已经做了 v2 数据审计，应将源文件数、映射无效值、重复/冲突样本、平衡采样规则和训练/验证/测试规模写入第四章。
3. **指标报告**：同刊相关论文常报告 Accuracy、Precision、Recall、F1，并有部分文章报告训练/测试时间。本文应继续保留 Macro-F1、每类指标、Bootstrap 区间、McNemar/配对置换检验和核心推理延迟。
4. **公平对比**：不能直接搬用官网摘要中的 99% 以上数字作为本文目标。不同论文的标签、数据划分、去重和类别平衡协议不同；正文应将这些论文作为方法路线背景，而不是可比实验结果。
5. **创新点措辞**：由于本文加权随机森林相对普通随机森林的差异未达到统计显著，建议使用“提出并评估基于单树验证性能的加权投票策略”，不要写“显著提升”。
6. **轻量化边界**：同刊论文会报告测试时间，但完整部署仍涉及特征提取、数据传输、批处理和监控。本文应将结果命名为“离线核心推理基准”，并在局限性中说明不等同于实际网关端到端吞吐。
