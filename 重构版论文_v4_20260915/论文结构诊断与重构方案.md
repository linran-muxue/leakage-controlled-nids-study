## 一、结论先说

导师的两条意见都成立，而且可以量化。问题不在文字多少，而在于**这篇稿子同时想当两篇论文**。

### 问题 1：一篇稿子里有两个互相冲突的主张

| 稿件位置 | 它主张什么 |
|---|---|
| 题目、摘要、第 4 章 | 提出 Risk-Calibrated Conformal Forest（RCCF），是一个新的集成学习方法 |
| 第 5 章结果 | RCCF 与等权随机森林几乎完全相同，而且更慢 |

支撑第二条的硬数据（来自 `results_rccf_evidence_v3b`、`results_weight_mechanism_v3`、`results_rccf_cic_natural_v3b`）：

| 证据 | 数值 |
|---|---:|
| RCCF − 等权卡方随机森林 Macro-F1 平均差 | +0.00108 |
| 逐种子精确 McNemar 检验 p 值（Holm 校正后） | 0.556 |
| 配对 Bootstrap 95% 区间 | [−0.0043, +0.0076]（跨 0） |
| 四专家在 505 条测试样本上的预测分歧条数 | 0 |
| 样本条件权重归一化熵（最大 1） | 0.99998 |
| 训练耗时 RCCF vs 等权 RF | 61.0 s vs 0.80 s |
| 推理耗时 RCCF vs 等权 RF | 0.152 s vs 0.041 s |

一句话：题目承诺「新算法」，数据回答「该机制在本文协议下没有改变任何一条预测」。审稿人读到第 5 章必然要问：**那么贡献到底是什么？** 现在的稿子没有正面回答。

### 问题 2：章节是「内部审查清单」，不是「论证结构」

下列小节直接来自项目内部的自我审查流程，被原样搬进正文：

- 4.7 *When can the gate change a prediction?*
- 4.8 *Gate identifiability, limiting propositions, and cost-benefit criterion*
- 5.7 *Reviewer-facing synthesis: claim, evidence, and boundary*

这些标题对作者是提醒，对读者是噪音——读者读到的是「作者在自查」，而不是「作者在论证」。其中 4.7、4.8 的内容本身有价值（它解释了机制为什么不生效），但位置和标题都错了：应当改写为**方法部分的可辨识性命题**与**讨论部分的机理解释**。

此外，中文稿「6 讨论」下面只剩 6.3，6.1 与 6.2 缺失，结构本身不闭合。

## 二、根因：研究问题没有收敛成一个

现有稿子并列回答了五个问题，彼此没有主次、没有因果链：

1. 卡方特征选择有没有用？
2. 加权投票有没有用？
3. 概率校准好不好？
4. 开放集能不能拒绝未知攻击？
5. 换数据集还行不行？

五个问题平铺，读者读完不知道主结论是什么。**结构乱的根因是主张太多，不是章节太少。**

## 三、新的主线（一句话主张）

> **在泄漏受控的条件下，样本条件集成加权对基于流特征的入侵检测几乎不产生可观测的判别增益；在已报告的差异中起主导作用的是评测协议（去重顺序、类别先验、划分与调参预算），而不是聚合策略本身。**

这条主线把现有的阴性结果从「缺陷」变成「论点」，并且给出正面贡献。支撑它的关键对照（同一批实验内部可比）：

| 差异来源 | 量级 | 数据来源 |
|---|---:|---|
| 聚合策略（RCCF − 等权 RF） | +0.0011 Macro-F1，不显著 | `results_rccf_evidence_v3b` |
| 特征视图（全特征 RF − 卡方 RF） | −0.0009 Macro-F1 | `results_cic_natural_baselines_v3b` |
| 类别先验（平衡 0.9618 vs 自然 0.8900） | **+0.072** | `results_rccf_cic_balanced_v3b` / `results_rccf_cic_natural_v3b` |
| 去重顺序（先划分后训练侧去重 vs 全局先去重） | 至多 +0.0060 | `results_protocol_sensitivity_v4` |
| 文件外推压力测试（同一模型换测试文件） | 0.33 – 1.00 Macro-F1 | `results_file_external_generalization_v3b` |
| 强基线（XGBoost − 等权 RF，5×3 嵌套 CV） | +0.0078，区间不跨 0 | `results_nested_modelwise_v1_5x3` |

**聚合策略造成的差异，被协议与数据划分造成的差异淹没**——这就是论文要讲的唯一一件事。

## 四、题目与摘要的调整方向

**原题**：Risk-Calibrated Conformal Forests for Auditable Network Intrusion Detection: A Leakage-Controlled Multi-Dataset Evaluation

问题：把 RCCF 放在标题首位，等于承诺算法优势，与结果自相矛盾。

**建议新题（主选）**

- 英文：*Protocol Sensitivity Dominates Model Choice in Flow-Based Network Intrusion Detection: A Leakage-Controlled Study of Conditional Ensemble Weighting*
- 中文：**协议敏感性主导模型选择：面向条件集成加权的泄漏受控网络入侵检测研究**

**备选（若导师希望保留方法名）**

- 英文：*Conditional Ensemble Weighting for Network Intrusion Detection: Identifiability Limits and Protocol Sensitivity*
- 中文：面向网络入侵检测的条件集成加权：可辨识性边界与协议敏感性

**摘要五段式骨架**

1. 背景（1 句）：公开入侵检测数据集上报告的模型差异，对去重、泄漏与类别先验高度敏感。
2. 问题（1 句）：样本条件集成加权被广泛假设为有效，但缺少泄漏受控下的可辨识性检验。
3. 方法与协议（2 句）：给出泄漏受控协议与两个总体定义；给出三个命题，说明门控在什么条件下必然不改变预测。
4. 结果（3 句）：主结果不显著（Δ=0.0011，p=0.556，区间跨 0，分歧 0 条，权重熵 0.99998）；协议变化带来 0.07 量级差异；外部数据 0.33–1.00。
5. 结论（1 句）：贡献是协议、可辨识性边界与失效地图，不是新的最优分类器。

## 九、如果导师坚持要「算法创新型」论文

当前证据不支持算法优势主张。若坚持算法创新，需要的是**新增研究**而不是改写：

1. 提出真正的新机制。失效原因已定位（专家高度相关 → 权重熵 0.99998 → 预测分歧 0），可行方向是**显式强制专家去相关**或**基于分歧触发而非全样本加权**。
2. 预注册假设与判定阈值，避免事后挑选。
3. 三个数据集上做 5×3 嵌套交叉验证，报告配对效应量与多重比较校正。
4. 复杂度分析与消融矩阵（专家数、去相关强度、触发比例）。
5. 与 XGBoost、LightGBM、ExtraTrees 在同等调参预算下比较。

预期工作量约 4–8 周，且结果仍可能为阴性。现有数据最稳妥的产出是本方案建议的「协议与边界」研究。
